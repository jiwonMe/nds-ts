        One script, two targets.
        
            
        The TypeScript compiler runs on your computer. What reaches the console is plain ES5 text, run by your browser on this page or by the Duktape interpreter inside the ROM.
        
          
        
          
        
            
          
              
        1. 
                main.ts
                
          Your game: one global TypeScript script.
          
              
          2. 
              
        2. 
                tsc
                
          Type-checks against ES5 and the SDK. Imports, Map and Promise are rejected here.
          
              
          3. 
              
        3. 
                game.js
                
          0 bytes of ES5 for the cartridge in the console.
          
              
          4. 
            
        
            
        
              
        
                
        In this browser
        
                
          
                  
        1. Canvas 2D paints both screens, Web Audio plays the tone.
          2. 
                  
        2. Colors are cut to RGB15 and text uses the same 3×5 font.
          3. 
                  
        3. The top screen keeps the DS limit of 1500 quads a frame.
          4. 
                
        
              
        
              
        
                
        On a Nintendo DS
        
                
          
                  
        1. script_gen.h embeds the same bytes as a C array.
          2. 
                  
        2. Duktape 2.7 runs them in a 512 KiB heap on the ARM9.
          3. 
                  
        3. libnds draws the top screen with 3D quads, the bottom as a bitmap.
          4. 
                  
        4. BlocksDS links a real .nds ROM inside Docker.
          5.

        What v0.1 does not do yet.
        
            
        nds-ts is a small 2D engine prototype. These are the edges you will meet first.
        
          
        
          
        
            
        
              
        Graphics
        
              
          
                
        • No hardware sprites, tilemaps or PNG import yet.
          • 
                
        • One built-in 16×16 sprite: the orb.
          • 
                
        • A frame past 1500 top-screen quads stops the game.
          • 
              
        
            
        
            
        
              
        Code
        
              
          
                
        • One global script per game, with no imports.
          • 
                
        • ES5 at runtime: no Map, Set or Promise.
          • 
                
        • Numbers use software floating point on the DS.
          • 
              
        
            
        
            
        
              
        Runtime
        
              
          
                
        • 512 KiB JavaScript heap, headers included.
          • 
                
        • Watchdogs stop a boot after 500 ms and a callback after 100 ms.
          • 
                
        • A frame that misses VBlank slows the game down.
          • 
              
        
            
        
            
        
              
        Sound and storage
        
              
          
                
        • One square-wave voice.
          • 
                
        • No save data, music sequencing or networking.
          • 
                
        • Not tested on physical hardware so far.
          • 
              
        
            
        
          
        
        
        
      
        

      
        
        
        
          
        
            
        Build your first ROM.
        
            
        You need Node.js 22.12 or newer. ROM builds also need Docker, which runs a pinned BlocksDS image with networking turned off.
        
          
        
          
          
            
        1. Install
          Clone the repository and install the locked dependencies.
          2. 
            
        2. Preview
          Opens the browser preview at port 5174.
          3. 
            
        3. Build the ROM
          Writes build/nds-ts-demo.nds for an emulator or flashcart.
          4. 
            
        4. Make it yours
          Point the same build at your own script.
          5. 
          
        
          
        
            
        
              Terminal
              
            
        
            
        $ git clone https://github.com/jiwonMe/nds-ts.git
$ cd nds-ts
$ npm ci
$ npm run dev
$ npm run build
$ npm run build -- examples/hinge-breakout/main.ts
